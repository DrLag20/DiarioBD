# 🌱 EcoTrack - Sistema de Monitoreo de Huella de Carbono Personal

**Autor:** Juan Pérez

**Descripción:**  
EcoTrack es una aplicación web que permite a los usuarios calcular, monitorear y reducir su huella de carbono mediante actividades diarias, consejos personalizados y retos ecológicos. Está diseñada para fomentar hábitos sostenibles y generar conciencia ambiental de manera práctica y accesible.

---

## 🌍 Descripción del Proyecto

EcoTrack nace con el propósito de combatir el cambio climático desde el nivel individual. Permite a cualquier persona conocer el impacto ambiental de sus acciones cotidianas (transporte, alimentación, consumo energético, etc.) y sugiere formas concretas de reducirlo.

Este proyecto puede ser utilizado por:
- Personas interesadas en la sostenibilidad.
- Instituciones educativas que buscan herramientas interactivas sobre cambio climático.
- Empresas que deseen ofrecer beneficios verdes a sus empleados.

---

## ⚙️ Funciones y Características

### 🔢 Cálculo de Huella de Carbono
- Algoritmo que calcula emisiones de CO₂ con base en hábitos diarios.
- Sección dedicada al transporte, consumo energético, alimentación y productos comprados.

### 📊 Seguimiento de Progreso
- Gráficas semanales y mensuales del progreso individual.
- Comparativas con la media nacional y mundial.

### 🎯 Retos y Recompensas
- Desafíos ecológicos semanales (ej: una semana sin usar el coche).
- Recompensas simbólicas y medallas digitales.

### 🧠 Consejos Personalizados
- Sugerencias prácticas según el estilo de vida del usuario.
- Alertas automáticas cuando se detectan hábitos de alto impacto ambiental.
